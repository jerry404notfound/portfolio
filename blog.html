The learning log / Engineering workflows

What digitizing an inspection form taught me about workflows.

Moving a form from paper to a screen is also a chance to think about the steps someone follows.

By Jerry Sun · Draft reflection

On this page

  1. Start with the task
  2. Make each question useful
  3. Test small changes
  4. My takeaway

Draft reflection based on my Maximo inspection-form work. I am still refining this article before publication.

Start with the task

When I started working with Maximo Inspection Forms, the visible task was to move questions from paper into a digital form. But I also needed to think about what the person completing the inspection would do next.

A question is part of a sequence. Its wording, response type, and position can change how easy that sequence is to follow.

Make each question useful

Required responses and conditional questions help define the workflow. A follow-up question can appear when an earlier answer makes it relevant.

For example, a sample inspection might ask whether a visible issue is present. If the answer is yes, a follow-up could request a description. This is an illustrative example, rather than a description of a specific company inspection.

  • Use wording that makes the requested observation clear.
  • Choose a response type that fits the question.
  • Show follow-up questions when their conditions are met.

Test small changes

Sometimes a form reports an error while changes are being submitted. Changing one thing at a time makes it easier to investigate what triggered the problem.

A useful record includes what changed, what I expected to happen, and what actually happened. It helps turn a vague error into something that can be investigated.

My takeaway

A useful digital form connects clear questions with a clear process. Learning to configure and test that process has helped me think more carefully about how people use engineering software.
