01 / PLANNED PROJECT

Connecting PI Historian & Maximo

Plan to combine power plant operating data with maintenance records and explore indicators that could support predictive maintenance.

  • PI Historian
  • Maximo
  • SQL
  • REST APIs
Explore the project plan

Status

Planned. Data access, implementation, and results are still to be established.

Goal

Connect equipment operating history with maintenance events to investigate patterns that may help identify developing equipment issues.

Planned approach

  1. Retrieve selected power plant time-series data from PI Historian through an available REST API, such as PI Web API.
  2. Retrieve corresponding asset and work-order records from Maximo through its REST API.
  3. Load the retrieved data into a SQL database, map common asset identifiers, align timestamps, and check missing values and data quality.
  4. Use SQL queries to compare operating trends with maintenance events and develop candidate condition indicators.
  5. Evaluate the indicators against historical records to assess their usefulness for predictive maintenance.

Intended outcome

A prototype data workflow and analysis that could support predictive maintenance decisions. Predictive performance has not yet been demonstrated.
